# E7. Demo scenario

**Status:** accepted, starts in parallel with E1 · **Module:** all · [BUSINESS-SPEC.md](../BUSINESS-SPEC.md)

## Goal

Have a repeatable demo for the jury on synthetic data. The same data speeds up the building of E2 and E3.

## User stories

1. As a team, we want a fictional person with synthetic data, so that we can show the full flow without the data of real people.
2. As a team, we want the data of this person to appear in several different types of sources, so that we can show how information is joined.
3. As a team, we want an address with a high Confidence Level in the data, so that we can show a correct Attribution.
4. As a team, we want an address with a low Confidence Level in the data, so that we can show that the scoring tells results apart.
5. As a team, we want an address to reject (for example an exchange) in the data, so that we can show that the scoring filters out wrong attributions.
6. As a team, we want the demo steps written down, so that we fit in the time of the film (3 min) and the presentation.
7. As a jury, we want to see that the data is synthetic, so that there is no doubt about its origin.

## Notes

- The task requires test scenarios on anonymised or synthetic data (Z p.3).
- The demo has 7 scored steps (Z p.5); the step of blockchain indicators depends on the decision about E4.
