# E6. Returning to a Case

**Status:** extra, done only if there is time · **Module:** M4. Official's view · [BUSINESS-SPEC.md](../BUSINESS-SPEC.md)

## Goal

The Analyst returns to a Case and sees what changed since the previous Analysis.

## User stories (in order of delivery)

1. As an Analyst, I want to start an Analysis for the same Case again manually, so that I can check whether something new appeared.
2. As an Analyst, I want to see the history of Analyses of a Case, so that I can return to an earlier result.
3. As an Analyst, I want to compare two Analyses, so that I see new and vanished Attributions and changes of the Confidence Level.
4. As an Analyst, I want to set up scheduled runs of the Analysis, so that I do not have to remember to repeat it.

## Open questions

## Risk
