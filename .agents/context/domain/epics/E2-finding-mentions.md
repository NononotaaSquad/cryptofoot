# E2. Finding Mentions

**Status:** accepted · **Module:** M2. Information search · [BUSINESS-SPEC.md](../BUSINESS-SPEC.md)

## Goal

Take the tedious walk through sources away from the Analyst. The search collects and marks; it does not judge anything.

## User stories

1. As an Analyst, I want to start an Analysis with one click, so that I do not search the sources myself.
2. As an Analyst, I want to get Mentions from a fixed, short set of sources (at most 2–3 public ones plus synthetic data), so that the result is predictable.
3. As an Analyst, I want to see which sources were checked, so that I know what the Analysis did not cover.
4. As an Analyst, I want to see for every Mention where it comes from, so that I can return to it.
5. As an Analyst, I want to see for every Mention the date and time of collection, so that I know for which moment the result is valid.
6. As an Analyst, I want to see which cryptocurrency addresses appeared in which Mention, so that I do not look for them in the content myself.
7. As an Analyst, I want a clear message when no Mention was found, so that I can tell no results apart from an error.

## Out of scope

- General internet search.
- Judging the reliability of Mentions (this is E3).

## Open questions
