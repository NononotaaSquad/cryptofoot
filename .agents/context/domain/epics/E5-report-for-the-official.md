# E5. Report for the official

**Status:** accepted · **Module:** M4. Official's view · [BUSINESS-SPEC.md](../BUSINESS-SPEC.md)

## Goal

A short answer instead of information overload. Basic flow: the Analyst enters data and gets a report, and the results are collected in a table.

## User stories

1. As an Analyst, I want to get one result as a table (address, Confidence Level, reference to the Mention), so that I do not put it together myself from many sources.
2. As an Analyst, I want to see Attributions from the highest Confidence Level down, so that I start with the strongest leads.
3. As an Analyst, I want to tell apart source facts, calculation results, and conclusions for verification, so that I do not mistake a lead for evidence.
4. As an Analyst, I want to read the report without technical terms, so that I understand it without IT knowledge.
5. As an Analyst, I do not want to see information that does not help the decision, so that I do not analyse noise.
6. As an Analyst, I want to be able to pass the report on (for example to my superior), so that another person can take up the verification.
